##Big data con mis palabras

**Qué es un Big Data:**
Es un conjunto de datos masivos, que generan complejidad porque son generados a gran velocidad además con ellos podemos analizar comportamientos. 

**Un ejemplo que sí es Big Data, y por qué:**
Un claro ejemplo de big data es el tránsito vehicular que analiza continuamente datos de geolocalización por GPS por medio de teléfonos móviles como por ejemplo waze que combina sensores de carreteras para medir la congestión urbana en tiempo real. 

**Un ejemplo que no es Big Data, y por qué:**

La encuesta de presupuestos familiares o una encuesta trimestral a empresas para poder medir el gasto o la inversión. No es big data, por que tiene baja frecuencia y recolección de datos se recoge de forma periódica mediante cuestionarios o validación de procesos estadísticos tradicionales.
